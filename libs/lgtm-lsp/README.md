# lgtm-lsp

Pure-Rust stdio JSON-RPC 2.0 language server orchestration SDK (`LspService`, `LspDiagnostic`, `LspHoverResult`, `LspLocation`, `LspWorkspaceSnapshot`) for LGTM. See [LSP SDK architecture](../../docs/architecture/lsp/index.md).

## Tasks

```sh
premise run //libs/lgtm-lsp:build
premise run //libs/lgtm-lsp:test
premise run //libs/lgtm-lsp:lint
premise run //libs/lgtm-lsp:format:check
```
