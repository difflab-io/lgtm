*lgtm.txt*  LGTM Neovim plugin shell

==============================================================================
STATUS                                                       *lgtm*

The previous plugin UI and review logic have been removed for a rewrite.
The package retains its loading entry points and this help page. There are
currently no LGTM commands, keymaps, review workflows or backend calls.

SETUP                                                        *lgtm-setup*

Add apps/lgtm.nvim from the repository to 'runtimepath', then run: >lua
    require("lgtm").setup()
    vim.cmd("runtime plugin/lgtm.lua")
<
setup() and setup({}) are inert. Previous options have no effect.
The shell requires no other plugins or running backend.

DEVELOPMENT                                                  *lgtm-development*

See apps/lgtm.nvim/README.md and e2e/README.md in the repository for
installation, plugin load checks and the retained Neovim E2E machinery.
