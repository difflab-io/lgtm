*lgtm.txt*  LGTM Neovim review UI plugin

==============================================================================
OVERVIEW                                                     *lgtm*

lgtm.nvim provides reactive Neovim UI scaffolding for two review workflows:
- Local Review (always on during normal buffer editing via LocalReviewService)
- PR Review (activated by selecting an open branch PR in pr-select-modal and
  opening a CodeDiff session via PrService)

==============================================================================
SETUP                                                        *lgtm-setup*

Add apps/lgtm.nvim from the repository to 'runtimepath', then run: >lua
    require("lgtm").setup()
    vim.cmd("runtime plugin/lgtm.lua")
<
setup() and setup({}) load CodeDiff, WhichKey, nvim-notify and
NuiComponents/NUI, initialize LocalReviewService, PrService and
ThreadsOverlay, and register :Lgtm and <leader>r WhichKey mappings without
opening windows on startup. Kak is loaded when available.

==============================================================================
COMMANDS AND KEYMAPS                                         *lgtm-keymaps*

Commands:
  :Lgtm pr               Open pr-select-modal for open branch pull requests
  :Lgtm threads          Toggle the right-hand threads-pane split
  :Lgtm comment          Open comment-editor at the cursor line
  :Lgtm thread           Open thread-detail-view for the thread at cursor
  :Lgtm resolve          Toggle resolved state for the thread at cursor
  :Lgtm submit           Open pr-submit-editor (Comment)
  :Lgtm approve          Open pr-submit-editor (Approve)
  :Lgtm request_changes  Open pr-submit-editor (Request Changes)

Default WhichKey mappings (<leader>r):
  <leader>rc             Draft local/PR comment or reply via comment-editor
  <leader>rp             Open pr-select-modal
  <leader>rt             Toggle threads-pane split
  <leader>ro             Open thread at cursor in thread-detail-view
  <leader>rx             Toggle thread resolved state
  <leader>rs             Submit PR review (Comment)
  <leader>ra             Approve pull request
  <leader>rr             Request changes on pull request
  ]c / [c                Jump to next / previous thread in buffer
