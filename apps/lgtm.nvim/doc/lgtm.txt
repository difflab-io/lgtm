*lgtm.txt*  LGTM reviews with saved source revisions

SETUP                                                        *lgtm-setup*

Install the LGTM CLI and Git, start `lgtm up --no-open`, then configure require("lgtm").setup with identity. The root lazy.nvim package installs NUI, NuiComponents and CodeDiff dependencies. Other managers need explicit dependencies; see README.md.

COMMANDS                                                     *lgtm-commands*

:Lgtm review                 Choose Working, Staged, Branch or PR.
:Lgtm directory [path]       Review saved files, including ignored content.
:Lgtm prs [repository URL]   Select an open branch PR.
:Lgtm sessions [completed]   Resume or inspect a saved review.
:Lgtm comment [line/file/general]
                            Compose feedback in the selected source pane.
:Lgtm files / threads       Open the file pane / cross-file discussions.
:Lgtm refresh                Capture another revision in the same session.
:Lgtm layout                 Toggle CodeDiff layout.
:Lgtm save                   Confirm saved review state.
:Lgtm export                 Markdown preview, file or clipboard.
:Lgtm sync                   Synchronize saved PR drafts without submitting.
:Lgtm complete               Complete a local review.
:Lgtm submit / reconcile     Submit remote review / recover an uncertain result.
:Lgtm close                  Close the view without completing the review.

KEYS                                                         *lgtm-keys*

<leader>rr/rb/rD/rp/rS       Working / branch / directory / PR / saved review.
c or <leader>rc             Comment on a line or visual range in a source pane.
<leader>rf/rg/rt/rx          File / general feedback / threads / export.
Enter/K                     Open a comment card.
Tab/Shift-Tab in modal      Select next/previous comment or reply.
c/e/dd/x in thread view     Reply / edit / delete / resolve.
q/Esc                       Close the modal and restore source focus.
]c/[c ]n/[n                 Navigate feedback.
za/zA gH                    Expand one/all cards; toggle overlays.
Ctrl-S                      Save composer; failed saves retain text.
f                           Toggle persistent review-file pane.
Enter in file pane          Select file.
m in tree / <leader>rm      Toggle file reviewed mark.
]f/[f Tab/Shift-Tab          Next/previous file or unreviewed file.
<leader>rs/ry/rq            Submit / synchronize drafts / close view.

setup.prefix remaps global keys. setup.mappings remaps supported component keys. Editing and deletion require an eligible owned comment. Remote resolution requires a published thread. Deletion asks for confirmation.

SAVED SOURCE                                                 *lgtm-snapshots*

Both source panes are read-only Git revision buffers. Working reviews capture saved working files; staged reviews capture index content. Branch and PR snapshots reuse existing commits. Directory reviews compare saved content with an empty baseline. Unsaved editor changes are not captured.

Snapshots live under $LGTM_HOME/snapshots/<repository-id>. The backend owns their Git objects and revision refs. Moving or deleting the original source cannot change a saved review. Refresh captures a new revision in the same session. Select historical feedback in :Lgtm threads to open its original source.

PR pushes preserve the session, pending review and draft bodies. GitHub supplies current coordinates and outdated status. Unsupported historical drafts remain local with a synchronization error. A push during submission requires a refresh; an uncertain result requires reconciliation.

Comments save immediately. PR line/file comments and replies synchronize to a private pending GitHub review; general feedback stays local until submission. Further feedback after confirmed submission starts a new review attempt. Closing a view does not submit or delete its feedback.

Standalone live-buffer notes and promotion have been removed. Existing note records remain stored and available through the archived notes read/export API scope.
